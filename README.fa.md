# Garage Rumble (گاراژ رامبل)

بازی مسابقه‌ای-رزمی ماشین کنترلی (RC)، **۱۰ نفره**، تحت مرورگر.
همه‌ی تصمیم‌های بازی روی **سرور** گرفته می‌شود (server-authoritative) و ضدتقلب چندلایه دارد.
ماشین‌ها روی پیستی می‌رانند که با نوارچسب کف یک کارگاه بزرگ کشیده شده.
بازیکن از روی راکت‌ها می‌پرد، مین می‌گذارد و سعی می‌کند اول برسد.
**رتبه از پیشرفت در پیست حساب می‌شود، نه از تعداد کشته‌ها.**

## اجرا

```bash
npm install
cp .env.example .env     # همه‌ی CHANGE_ME ها را با رمز تصادفی عوض کن (openssl rand -hex 32)
npm run db:up            # Postgres در Docker روی پورت 5433
npm run dev              # API :3000 · سرور بازی :2567 · کلاینت http://localhost:5173
```

مرورگر را روی <http://localhost:5173> باز کن، اسم بده و «Find a race» را بزن.
در حالت dev، اگر صندلی خالی بماند، بعد از ۱۵ ثانیه بات‌ها جایش را پر می‌کنند.

## ضدتقلب در یک نگاه

- کلاینت فقط **دکمه‌ها** را می‌فرستد (۸ بیت در هر تیک).
  - این‌ها همه روی سرور حساب می‌شود: موقعیت، سرعت، برخورد، آیتم، آسیب، cooldown، چک‌پوینت، دور، رتبه و نتیجه.
- پیامی برای «موقعیتم این است»، «رسیدم» یا «جانم ۱۰۰ است» **اصلاً وجود ندارد**.
  - هر پیام ناشناخته امتیاز تقلب می‌گیرد و تکرارش به اخراج می‌رسد.
- ارسال ورودی بیشتر از نرخ تیک هیچ سودی ندارد: سرور در هر تیک فقط یک ورودی مصرف می‌کند.
- سرور هر تیک چند محدودیت را چک می‌کند:
  - سرعت
  - شتاب
  - چرخش
  - جابه‌جایی ناگهانی (teleport)
  - رفتن داخل دیوار
  - پرش غیرممکن
  - رد کردن چک‌پوینت
- **امتیاز مشکوک‌بودن**:
  - خطاهای ناشی از شبکه کم‌کم پاک می‌شوند.
  - حرکت غیرممکن تکراری، امتیاز را سریع بالا می‌برد.
  - سطوح به ترتیب: بررسی دستی، رد نتیجه، باطل شدن مسابقه، تعلیق ۲۴ ساعته.
- API فقط نتیجه‌ای را قبول می‌کند که با ثبت اولیه‌ی مسابقه یکی باشد: همان سرور، همان seed و همان بازیکن‌ها.
- replay: از روی ورودی‌ها می‌شود کل مسابقه را دوباره شبیه‌سازی و راستی‌آزمایی کرد.

جزئیات: [docs/system-design/03-anti-cheat.md](docs/system-design/03-anti-cheat.md)

## تست و بار

- ۷۳ تست خودکار دارد.
- همه‌ی سناریوهای ضدتقلبی که خواسته بودی تست شده‌اند.
- تست بار روی یک لپ‌تاپ، با ۲۰ مسابقه‌ی هم‌زمان و ۲۰۰ کلاینت:
  - خطا: صفر
  - مصرف CPU: ۲۲٪ از یک هسته
  - p99 تیک: ۰٫۷۷ میلی‌ثانیه
  - پهنای باند: حدود ۱۲ KB/s برای هر بازیکن

- یک پیست
- پرش
- ۶ آیتم به‌علاوه‌ی تفنگ پایه
- ضدتقلب
- ثبت نتیجه
- replay
- تست بار
